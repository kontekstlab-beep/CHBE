# Запуск paper-стратегии на Binance Futures testnet

Цель — проверить главный незакрытый вопрос: переживает ли тонкий edge mean-reversion
**реальное исполнение** (филлы maker-лимиток, проскальзывание). Бэктест на это не отвечает.

Торговля идёт на **testnet** (тестовые деньги, реальные механики биржи). Реальные
средства не задействованы.

## 1. Получить ключи testnet (делаете вы)
1. Откройте https://testnet.binancefuture.com и войдите (можно через GitHub/почту).
2. Пополните тестовый баланс: раздел **USDⓈ-M Futures** → кнопка faucet/«Get Assets»
   (даёт тестовые USDT).
3. Внизу страницы найдите **API Key** → создайте ключ. Права: **только фьючерсная
   торговля**, БЕЗ вывода средств. Скопируйте **API Key** и **Secret**.

> Ключи вводите ТОЛЬКО вы. В коде они не хранятся — читаются из окружения.

## 2. Задать ключи в окружении
PowerShell (текущая сессия):
```powershell
$env:BINANCE_TESTNET_KEY = "ваш_ключ"
$env:BINANCE_TESTNET_SECRET = "ваш_секрет"
```
Git Bash:
```bash
export BINANCE_TESTNET_KEY=ваш_ключ
export BINANCE_TESTNET_SECRET=ваш_секрет
```

## 3. Предполётная проверка (без сделок)
```bash
python run_paper.py --check
```
Должно вывести баланс USDT и число рынков. Нулевой баланс → пополните через faucet.

## 4. Запуск живого цикла на testnet
```bash
python run_paper.py --live --testnet
```
Что делает: раз в час на закрытом баре по каждой из 10 монет проверяет сигнал
(z<−2), ставит maker-лимитку на покупку, ведёт позицию (выход на среднем / стоп 8% /
тайм 8ч), сайзинг 5% от реального баланса. Логи — в консоль и в `paper.log`.
Состояние — в `paper_state.json` (переживает рестарт).

Остановить: Ctrl+C. Запустить снова — продолжит с сохранённого состояния.

## 5. Что смотреть (несколько недель)
- **Fill rate лимиток**: сколько сигналов реально исполнилось (в логе — «ПОЗИЦИЯ
  открыта» против «лимитка отменена»/«ордер отклонён»). Ключевой вопрос: postOnly-
  лимитки на дне пролива могут отклоняться/не исполняться.
- **Цена входа против модели**: фактический fill vs сигнальная цена.
- **Итоговый P&L/сделку** против бэктеста (~+0.12–0.15%). Если близко — edge живой;
  если заметно хуже — исполнение съедает тонкий edge (честный отрицательный ответ).

## Замечания
- Процесс должен работать непрерывно (для многонедельного теста — VPS/отдельная
  машина; локально — не выключать/не усыплять ПК).
- Требуется `ccxt` (`pip install ccxt`).
- Плечо ставится 1x (без риска ликвидации на лонгах). Мелкие ордера ниже минимального
  номинала биржи пропускаются (видно в логе).
- Это НЕ инвестиционная рекомендация. На реальные деньги — только после устойчивого
  положительного результата на testnet, и осознанно.
